How it works

Prefixed classes

Every class starts with aw-, so it never collides with your own CSS. Variants add a suffix: aw-btn-primary, aw-badge-success.

Cascade layers

Styles live in @layer athwin.* (reset, theme, base, components, utilities). Your unlayered CSS always wins, no !important needed.

Design tokens

Colors, radii, shadows and fonts are CSS custom properties (--aw-*) you can override anywhere.

!
Includes a resetAthwinUI applies a small reset and base styles (body font, background, link colors) to the whole page.
Foundations

Layout & typography

Containers, spacing primitives and text styles.

Container & section

aw-container centers content up to --aw-container (1160px). aw-section adds responsive vertical padding.

Stack

Vertical flex column. Set spacing with --aw-gap (default 1rem).

Cluster

Horizontal, wrapping row with vertical centering. Ideal for button groups and badges.

Grid & auto grid

aw-grid uses --aw-cols equal columns (collapses to one column under 700px). aw-grid-auto fits as many columns as possible using --aw-min (default 220px).

Between, center & divider

Typography

Note: aw-h1–aw-h3 and aw-display are classes, so you can apply them to any element (use the right tag for accessibility).

Components

Buttons & surfaces

Actions, cards, badges and avatars.

Buttons

Use aw-btn on <button> or <a>. Add one variant, optionally a size and shape.

Cards

aw-card with optional aw-card-header, aw-card-footer and aw-card-hover (lift on hover).

aw-panel is a subtle inset box (used for callouts), and aw-surface sets the surface background color.

Badges

Avatars

Put initials or an <img> inside. Sizes: aw-avatar-sm, default, aw-avatar-lg.

Customize

Theming & tokens

Everything is driven by CSS custom properties on :root.

Dark mode

AthwinUI follows the system setting by default. Force a theme with data-aw-theme on <html>, or scope it with .aw-dark on any container.

Override tokens

Remember to override the dark-theme values too ([data-aw-theme="dark"]) if you use dark mode.
