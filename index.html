Quick start

One link. That's it.

Zero dependencies

Add this inside your HTML <head>. For local development, keep athwin.css beside your page and use the relative path.

<link rel="stylesheet" href="https://raw.githubusercontent.com/D-gger/athwinui/refs/heads/main/athwin.css">

For production CDN delivery, consider publishing a versioned release or using a CDN that serves GitHub files.

Is JavaScript required?

No. The library styles HTML elements. Add JavaScript only when your application needs interactive behavior.

Can I customize the colors?

Yes. Override the --aw-* CSS custom properties on :root or a container.

08 / Helpers

Utility classes

Small helpers for spacing, alignment, width, and visibility.

.aw-text-center
