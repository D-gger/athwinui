Quickstart & CDN Link

Include AthwinUI directly in the <head> of any HTML document without NPM or build tooling.

1. Direct Link Integration

Paste the raw GitHub CDN URL into your project's header:

<link rel="stylesheet" href="https://raw.githubusercontent.com/D-gger/athwinui/refs/heads/main/athwin.css">

2. Theme Control

AthwinUI respects user system preference by default. Explicitly enforce Light or Dark mode by setting data-theme on your <html> tag:

<html data-theme="dark"> <!-- Explicit Dark Mode -->
<html data-theme="light"> <!-- Explicit Light Mode -->

Buttons

Use button classes on <button>, <a>, or <input> tags.

<button class="ath-btn ath-btn-primary">Primary Button</button>
<button class="ath-btn ath-btn-outline">Outline Button</button>
<button class="ath-btn ath-btn-ghost">Ghost Button</button>

Glassmorphism Container

Includes backdrop-blur filtering, border transitions, and soft drop shadows.

<div class="ath-card">
  <h4>Card Title</h4>

</div>

Form Controls

Styled inputs, dropdown selects, and textareas with focus ring indicators.

<div class="ath-form-group">
  <label class="ath-label">Email Address</label>
  <input type="email" class="ath-input" placeholder="user@domain.com">
</div>
